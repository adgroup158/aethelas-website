03 About aethelas.in a public, open-source project
✦ About This Website

Aethelas.in — The Community Website

This website is a public, open-source project built by and for the Aethelas community. It serves as the central hub for learning about Aethelas, exploring the technology, and connecting with the community.

The site is hosted on GitHub Pages and maintained by the Aethelas team with contributions from the community. Every page is open-source and welcomes contributions.

04 Contributing to aethelas.in how to help
📖 Contributing Guide

How to Contribute

If you want to help improve this website, here's how:

  • Fork the repository — github.com/adgroup158/aethelas-website
  • Make your changes — improve content, fix bugs, or add new features
  • Submit a pull request — describe your changes and why they matter
  • Get reviewed — the team will review and merge your contribution

💡 Tip: Start with small contributions — fix a typo, improve a sentence, or update a link. Every contribution counts!

06 Contributor Recognition celebrating our community
🏆 Contributor Recognition

Community Contributors

We believe in recognizing every contribution. Here are the ways we celebrate our community:

  • Contributor Badges — Earn badges for contributions to code, documentation, or community
  • Featured Contributors — Top contributors are featured on the website
  • Community Spotlight — Regular shout-outs in community updates
  • Open-Source Credit — All contributors are credited in the repository
